# 📜 Prisma Migrations History

This directory contains the immutable SQL migration history for **SecureFlow**.

---

## 📁 Directory Structure

Each directory represents an incremental database migration generated by Prisma CLI:

- **Folder Naming Format**: Numeric timestamp format `YYYYMMDDHHMMSS/` (e.g., `20260617164442/`, `20261031085913/`).
- **`migration.sql`**: The specific raw SQL queries (DDL) executed against the PostgreSQL database for that version.
- **`migration_lock.toml`**: Tracks the database provider (`postgresql`) to prevent accidental cross-engine execution.

## 🛠️ Key Migration Commands

| Task                               | Command                                       | Environment               |
| ---------------------------------- | --------------------------------------------- | ------------------------- |
| **Create & apply local migration** | `npx prisma migrate dev --name <name>`        | Local Development         |
| **Apply pending migrations**       | `npx prisma migrate deploy`                   | Production / CI / Staging |
| **Check migration status**         | `npx prisma migrate status`                   | Any                       |
| **Reset local database & reseed**  | `npx prisma migrate reset`                    | Local Development         |
| **Resolve failed migration**       | `npx prisma migrate resolve --applied <name>` | Troubleshooting           |

For comprehensive documentation on schema models, database seeding (`seed.ts`), and workflow details, refer to the parent [Prisma Documentation](../README.md).
